# VS Code custom config

Somewhere to keep a record of my VS Code preferences and list the extensions I install.


## Extensions

- [EditorConfig](https://marketplace.visualstudio.com/items?itemName=EditorConfig.EditorConfig)
- [Monokai Pro](https://marketplace.visualstudio.com/items?itemName=monokai.theme-monokai-pro-vscode)
- [Nunjucks](https://marketplace.visualstudio.com/items?itemName=ronnidc.nunjucks)


## Settings

The user settings file is located at `~/Library/Application Support/Code/User/settings.json`; this is the [settings config](./settings.json).


## Keybindings

The user keybindings file is located at `~/Library/Application Support/Code/User/keybindings.json`; this is the [settings config](./keybindings.json).
